# JSX Essentials

An interactive React and Vite reference for learning JSX syntax, props, events, conditional rendering, lists, keys, composition and safe raw HTML handling.

![JSX Essentials preview](screenshot.png)

## Features

- Clear explanations with working JSX examples
- Interactive counters, toggles, inputs and list-key demos
- Dark and light theme with saved preference
- Responsive cards, code examples and accessible controls
- Fixed branded header with icon-only links in the footer
- Floating go-to-top control with smooth scrolling

## Tech stack

React, Vite, styled-components and React Icons.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```
